🎙️ Python Voice Assistant

A smart desktop Voice Assistant built with **Python** that can understand voice commands and perform various tasks such as opening applications, searching the web, controlling system settings, and responding with natural speech.

---
 📌 Features

 🗣️ Speech Interaction
- Speech-to-Text using SpeechRecognition
- Text-to-Speech using Microsoft Edge TTS
- Voice-based command execution

🌐 Browser Controls
- Open Google
- Open YouTube
- Search Google
- Search YouTube
- Play songs on YouTube

💻 Application Launcher
- Open Notepad
- Open Calculator
- Open Paint
- Open Microsoft Word
- Open Microsoft Excel
- Open Microsoft PowerPoint
- Open Visual Studio Code
- Open Google Chrome

⚙️ System Controls
- Check Battery Percentage
- Take Screenshot
- Increase Volume
- Decrease Volume
- Mute Volume
- Unmute Volume
- Increase Brightness
- Decrease Brightness
- Get Current Brightness
- Set Brightness Percentage

📅 Utility Functions
- Tell Current Time
- Tell Current Date
- Greeting Responses
- Exit Voice Assistant

🚀 Installation
1. Clone the repository

```bash
git clone https://github.com/ShlokShirole/python-Task1-Voice-Assistant.git
```
 2. Move into the project folder

```bash
cd python-Task1-Voice-Assistant
```
 3. Install dependencies

```bash
pip install -r requirements.txt
```

If you don't have a requirements file, install:

```bash
pip install SpeechRecognition edge-tts pygame pyautogui psutil screen-brightness-control pyaudio
```

---

▶️ Run the Project

```bash
python app.py
```
